How it works

01 · Input

Routine CBC values (WBC, differential, hemoglobin, platelets and more). Ratios such as NLR, PLR and MLR are calculated automatically.

02 · Model

A regularised Logistic Regression gives a screening score from 0 to 1. Blank values are treated as typical.

03 · Flag

The threshold was chosen so about 90% of leukemia cases in the development data are caught, because a missed case costs more than a false alarm.

04 · Explanation

Each value's contribution to the score is shown, so a flag is never a black box.

Data: LeukoAlert routine CBC dataset

11 files from 7 hospitals. Models are trained only on the development files; every other file is used only for testing. Counts are raw records before cleaning.

Limitations

  • This is a student research prototype, not a diagnostic tool.
  • The score is not a probability. Training data is 33% leukemia, while real-world prevalence is about 2–5%; at that rate roughly 1 in 3–4 flagged people have leukemia.
  • Recall on unseen hospitals was below the 90% target (about 87–88%), so some cases are missed. Cases with near-normal counts are the hardest.
  • The dataset has no patient identifiers, so repeat blood tests from one person may appear in both training and test data.
  • The training data may not represent Pakistani patients. Local validation would be needed before any real use.
  • Missing values, laboratory units and data quality affect results. Feature contributions explain the model, not medical causation.
